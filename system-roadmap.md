# MyClass2026 - System Summary & Roadmap

## 1. Overview
**MyClass2026** is a comprehensive, feature-rich Learning Management System (LMS) and Educational Platform. It is designed to manage the end-to-end educational lifecycle, from administrative routing and school hierarchies to real-time student examinations, behavior tracking, and communication.

**Project Type**: FULL-STACK WEB APPLICATION (with offline-first capabilities)

## 2. Tech Stack
- **Backend**: Laravel 12.0, PHP 8.2+, MySQL/SQLite
- **Frontend**: Vue.js 3, Inertia.js, Tailwind CSS v4, Quasar Extras
- **Real-time & Offline**: Firebase 11, Pusher/Laravel Echo, Dexie.js (IndexedDB for offline capabilities), Web Push Notifications
- **Key Integrations**: 
  - `spatie/laravel-permission` (Role-based access)
  - AI & Parsing: `@google/generative-ai`, `openai`, `tesseract.js` (OCR)
  - External Utilities: `quagga2` (Barcode), `qrcode.vue`, `echarts`

## 3. Core Modules & Features

### 🏫 Academic Organization & Administration
- **Hierarchy Management**: Schools, Academic Years, Semesters, Stages, and Grades.
- **Classroom & Subject Routing**: Manages Classrooms, Subjects, Topics, and Teacher allocations (`ClassroomSubjectTeacher`).
- **HR & Permissions**: Advanced roles separation (Admin, Teacher, HR, Student, Parent) via distinct route files (`admin.php`, `r_hr.php`, `r_teacher.php`, etc.).

### 📚 Curriculum & Course Management
- **Curriculum Mapping**: Curriculum, Lesson Plans, and detailed `CourseManagement` systems.
- **Weekly Plans**: Systematic weekly planning (`WeeklyPlan`, `WeeklyPlanSession`) linked to specific subjects.

### 📝 Assessment & Examination Engine 
- **Exams (`QuExam`) & Quizzes**: Extensive examination system supporting various question types and attempt tracking.
- **Qudrat & Resumes**: Specialized testing modules (`QudratQuantitative`, `ResumeQuestion`).
- **Offline & Real-time Delivery**: Support for offline exam taking and auto-save (via Dexie/localStorage) with Firebase real-time signaling for live quiz sessions.

### 🌟 Behavior, Rewards, & Productivity
- **Behavior Tracking**: `StudentBehavior`, `BehaviorIncident`, allowing point-based actions and rewards (`DpReward`).
- **Productivity Tools**: Pomodoro Timer (`PomodoroSession`), Daily Tasks (`DpDailyTask`), and Calendar systems.
- **Skills System**: Skill tracking (`UserSkillProgress`), practice sessions, and awards.

### 💬 Communication & Media
- **Messaging Engine**: Real-time Chat (`Conversation`, `Message`), Chatbot integration, and Push Notifications.
- **Documentation & Announcements**: Centralized documentation portal and landing pages.
