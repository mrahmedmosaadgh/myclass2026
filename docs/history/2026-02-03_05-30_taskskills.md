## 🌐 ROUTES SUMMARY

### Student Routes (Authenticated Users)

#### Browse & Practice
```
GET  /skill-practice/categories              → Browse skill categories
GET  /skill-practice/categories/{id}         → View category details
GET  /skill-practice/skills                  → List all skills
GET  /skill-practice/skills/{skill}          → View skill details + progress
```

#### Practice Session
```
POST /skill-practice/skills/{skill}/start    → Start practice session
POST /skill-practice/practice/next-question  → Get next adaptive question
POST /skill-practice/practice/submit-answer  → Submit answer & get feedback
POST /skill-practice/practice/end-session/{session} → End session
```

#### Progress & Awards
```
GET  /skill-practice/progress                → View all skill progress
GET  /skill-practice/progress/{skill}        → View specific skill analytics
GET  /skill-practice/awards                  → View earned awards/badges
```

### Teacher/Admin Routes (Role: teacher|admin)

#### Skill Management
```
GET    /admin/skills                         → Admin dashboard
GET    /admin/skills/categories              → List categories
GET    /admin/skills/skills                  → List all skills
POST   /admin/skills/skills                  → Create new skill
PUT    /admin/skills/skills/{skill}          → Update skill
DELETE /admin/skills/skills/{skill}          → Delete skill
```

#### Question Linking
```
POST   /admin/skills/skills/{skill}/link-questions        → Bulk link questions
DELETE /admin/skills/skills/{skill}/unlink-question/{id}  → Remove question
GET    /admin/skills/skills/{skill}/linked-questions      → View linked questions
```

## 🎯 QUICK ACCESS GUIDE

### For Students
1. **Start Practicing:** Navigate to `/skill-practice/categories`
2. **View Progress:** Navigate to `/skill-practice/progress`
3. **Check Awards:** Navigate to `/skill-practice/awards`

### For Teachers/Admins
1. **Manage Skills:** Navigate to `/admin/skills`
2. **Create Skills:** POST to `/admin/skills/skills`
3. **Link Questions:** POST to `/admin/skills/skills/{skill}/link-questions`

### API Workflow Example
```javascript
// 1. Browse skills
GET /skill-practice/skills

// 2. Start practice
POST /skill-practice/skills/123/start

// 3. Get question
POST /skill-practice/practice/next-question
{ session_id: 456 }

// 4. Submit answer
POST /skill-practice/practice/submit-answer
{ session_id: 456, answer: {...}, time_taken: 5000 }

// 5. End session
POST /skill-practice/practice/end-session/456
```
