# Login Component Redesign (v1.2) - March 20, 2026

## Overview
Replaced the basic `Login.vue` with a fresh, highly-aesthetic, split-panel premium design (`LoginV12.vue`), featuring an animated visual side and structured glassmorphism components.

## Backend Changes
- **LoginController**: Implemented a clean class-based controller `App\Http\Controllers\Auth\LoginController` replacing the closure-based logic in `routes/web.php`.
- **LoginRequest**: Implemented `App\Http\Requests\Auth\LoginRequest` with a robust rate-limiting feature (`throttle` middleware to prevent brute force).
- **Session DB Fix**: Encountered a `500 Internal Server Error` during testing because the application was lacking a `sessions` table. Temporarily switched the `SESSION_DRIVER` to `file` in `.env`.
- **Routes**: Added `/login-v12` as a "safe preview" route to prevent interfering with existing user flows before completion. Placed above `/login/{school_slug}` to avoid parameter collision.

## Frontend UI (LoginV12.vue)
- **Split Panel Design**: 
  - Left Panel: Form with email, password (show/hide toggle), and remember me.
  - Right Panel: Animated gradient mesh with floating glassmorphic feature cards and a particle layer.
- **Animations**:
  - Horizontal shake keyframe animation for inputs when validation errors occur.
  - Ripple effect with glowing focus rings on the input fields.
- **Responsiveness**: Re-flows into a stacked layout for mobile devices, hiding the decorative elements.
- **i18n Readiness**: `dir` attribute is bound dynamically to the locale (`rtl` or `ltr`)

## Status
- Safe preview route is tested and complete.
- Inertia validation errors (e.g., incorrect credentials) are properly caught and mapped.
- Awaiting final swap to replace the legacy `/login` route.
