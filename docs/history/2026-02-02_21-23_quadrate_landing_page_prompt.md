# Quadrate Landing Page - AI Build Prompt
**Created:** 2026-02-02 21:23:26 | **Stack:** Laravel + Vue.js + Inertia.js

## 🎯 Project Goal
Create a stunning, modern landing page for **Quadrate** - a professional online presence platform. High-performance, conversion-focused design.

## 🏗️ Technical Stack
- **Backend:** Laravel 11.x, `QuadrateController`, route `/quadrate`
- **Frontend:** Vue 3 Composition API at `resources/js/Pages/Quadrate/LandingPage.vue`
- **Styling:** Vanilla CSS, mobile-first, glassmorphism effects
- **Performance:** Lazy loading, WebP images, smooth animations

## 🎨 Design Requirements
**Colors:** Modern gradient (deep blue→cyan or emerald→teal), NO purple/violet, dark mode with glassmorphism
**Typography:** Inter/Outfit for headings, Inter/Roboto for body, fluid responsive scale
**Effects:** Scroll animations, hover states, gradient overlays, subtle parallax

## 📐 Page Sections
1. **Hero:** Headline, subheadline, 2 CTAs, animated gradient background, hero image
2. **Features:** 6-8 features in glassmorphic cards, grid layout, staggered animations
3. **How It Works:** 3-4 step timeline with progressive reveal
4. **Showcase:** 3-6 example projects, masonry/grid with hover zoom
5. **Testimonials:** 3-6 customer quotes with avatars, card carousel
6. **Pricing:** 3 tiers (Free/Pro/Enterprise), monthly/yearly toggle
7. **CTA:** Final conversion message, email signup, trust indicators
8. **Footer:** Multi-column navigation, social icons, copyright

## 🚀 Performance Targets
- LCP < 2.5s, FID < 100ms, CLS < 0.1
- Lighthouse score > 90 all categories
- WCAG AA accessible
- Responsive: 320px→1440px+

## 🔧 Implementation Phases
1. **Backend:** Route, controller, data props
2. **Structure:** Main component + reusable cards (Feature, Testimonial, Pricing, CTA)
3. **Styling:** CSS variables, mobile-first, animations
4. **Interactivity:** Scroll animations (Intersection Observer), smooth scroll
5. **Optimization:** Image optimization, lazy loading, performance testing
6. **Testing:** Cross-browser, responsive, accessibility, performance audit

## ✅ Success Criteria
- Visually stunning first impression
- Smooth 60fps animations
- Fully responsive all devices
- Fast load < 3s on 3G
- Clear conversion path
- NO generic templates
- NO purple/violet colors
