# Admin Weekly Workflow Guide Created

## Summary
Created a comprehensive documentation guide for the Administrator to manage the Weekly Plans System.

## File Location
`docs/weekly_system/ADMIN_WEEKLY_WORKFLOW_GUIDE.md`

## Contents
- **Initial Setup:** Instructions for setting the active school context (Schedule/Semester).
- **Weekly Routine:** Step-by-step process for:
    1.  Selecting the target week.
    2.  Generating/Syncing plans from the schedule.
    3.  Monitoring teacher progress.
    4.  Distributing plans via PDF/Print.
- **Troubleshooting:** Common issues and solutions.
